프로젝트 생성

## git 로컬 레파지터리 생성
git init

## 원격 레파지터리 연결
git remote add origin [github-url]
ex) git remote add origin https://github.com/GoodPineApple/oz-todo.git

### 연결 확인
git remote -v

## 원격 레파지터리 받기
github Settings - Collaboratos - [Add people]

## 원격 레파지터리 받는 쪽
1. 팀 폴더를 만들기
2. 팀 폴더 기반으로 vscode열기
3. git clone [github url]
4. clone받은 폴더 기준으로 vscode 다시 열기

## 충돌 났을 때.
1. git pull origin main 으로 강제로 코드 가져오기
2. (설정 알림이 나오면) git config pull.rebase false
3. 격자무늬 충돌알림 마크보고 최종 코드 결정해서 저장하기
4. add, commit, push 하기

# 브랜치 관련 명령어
## 브랜치 목록 확인
git branch 

## 브랜치 생성
git branch [branch-name]

## 브랜치 이동
git checkout [branch-name]

## 브랜치 생성+이동
git checkout -b [branch-name]
